## QUESTION 1


__What was the earliest year that the name ‘Felisha’ was used?__

The earliest year that the name “Felisha” was used in the dataset is 1964. This indicates that the name started appearing in the U.S. birth records from that year onward. By examining the dataset, we can see that the name gained popularity gradually after its first recorded use.

```{python}
# Q1
felisha = df.loc[df['name']=='Felisha']
#felisha = df.query('name== "Felisha"')

(
    ggplot(felisha, aes(x='year', y='Total'))
    + geom_line(color='blue')
    + ggtitle(f"Popularity of Felisha")
    + scale_x_continuous(limits=[1950,2020], format='d')
    + geom_rect(xmin = 1964, ymin = 0, xmax = 2007, ymax = 250, color = 'blue', fill = 'blue', alpha = .2)
    + geom_text(x=1985, y=150, label = 'Era of Felisha', size= 7, color='red')
    + geom_vline(xintercept=1964, color='red', linetype='dashed', size = 2)
    
)


```


## QUESTION 2

__What year had the most babies named 'David'? How many babies were named 'David' that year?__

The year with the most babies named “David” was 1955, with a total of 64754.6 babies given that name. This graph shows that the name David was especially popular during that year, reflecting naming trends in the U.S. at the time. By examining the dataset, we can see how its popularity changed over the years.

```{python}
# Q2
# Filter for David and group by year
david = (
    df.query('name == "David"')
      .groupby('year', as_index=False)['Total']
      .sum()
      
)
# Get max year and value
year_max = david.loc[david['Total'].idxmax(), 'year']
max_count = david['Total'].max()

# Plot
(
    ggplot(david, aes(x='year', y='Total'))
    + geom_line(color='blue')
    + ggtitle("Most babies named 'David'")
    + scale_x_continuous(limits=[1950, 2020], format='d')
    + geom_vline(xintercept=year_max, color='red', linetype='dashed', size=2)
    + geom_text(x=1967, y= 60000, label= "Babies named David", size=7, color='red')
)
```
