# Can you build a model that predicts the year a house was built? Note this is a regression ML model, not a classifier. Report appropriate evaluation metrics for the model. Explain the model and the evaluation metrics you used to determine if the model is good.

-I built a Random Forest Regressor to predict the year a house was built (yrbuilt). The model captures nonlinear relationships between dwelling and neighborhood features. Evaluation metrics show good performance: the MAE indicates the predictions are on average within a few years of the true value, and the R² score shows the model explains most of the variance. Feature importance highlights the most influential variables, helping understand what drives house age. Overall, Random Forest is accurate and reliable for this regression task.-

```{python}
# Features and Target
x = JOIND.select_dtypes(include="number").drop(columns=["yrbuilt", "before1980"])
y = JOIND["yrbuilt"]

x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.2, random_state= 42)

```


```{python}
# Build the model
reg_model = RandomForestRegressor(n_estimators=3, random_state=42).fit(x_train, y_train)
```

```{python}
# Predict
y_pred = reg_model.predict(x_test) 
```

```{python}
# Evaluation metrics
mae = mean_absolute_error(y_test, y_pred)
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)

print(f"MAE: {mae:.2f}")
print(f"MSE: {mse:.2f}")
print(f"RMSE: {rmse:.2f}")
print(f"R² Score: {r2:.3f}")


# Feature importance for RandomForestRegressor
feat_importances = pd.DataFrame({
    'feature': x_train.columns,
    'importance': reg_model.feature_importances_
}).sort_values('importance', ascending=False).reset_index(drop=True)

# Plotting top 15 features
topn = 15
df_plot = feat_importances.head(topn).copy()
df_plot = df_plot.iloc[::-1]  # reverse order for horizontal bars

p = (
    ggplot(df_plot, aes(x='feature', y='importance'))
    + geom_col(fill="steelblue")
    + coord_flip()
    + ggtitle(f"Top {topn} Feature Importances")
    + theme_minimal()
)
p
```
