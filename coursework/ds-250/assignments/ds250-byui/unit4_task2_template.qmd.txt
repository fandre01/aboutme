## QUESTION 1

__Describe the quality of your classification model using 2-3 different evaluation metrics.__ You also need to explain how to interpret each of the evaluation metrics you use. 

_I evaluated the classifier using Accuracy, Precision, Recall, F1-score, and ROC AUC.

Accuracy tells me overall how often the model is correct on the test set.

Precision (for “before 1980”) indicates the fraction of houses predicted as old that really are old — useful when false alarms are costly.

Recall indicates the fraction of actual old houses the model successfully found — useful when missing old houses is costly.

F1 score balances precision and recall.

ROC AUC measures the model’s overall ability to separate old vs. newer houses using predicted probabilities, independent of the classification threshold.
The confusion matrix shows the exact counts of TP, TN, FP, and FN, letting us see which error type dominates and informing how to adjust the model based on the project objective_

```{python}
# create the binary target before_1980

df["before1980"] = np.where(df["yrbuilt"] < 1980, 1, 0)

print("Value counts for target (1=before 1980)")
print(df["before1980"].value_counts())
```


```{python}
# select the features (X) and target (Y)
# use only numeric features(drop the yrbuild and the new target)
x = df.select_dtypes(include="number").drop(columns=["yrbuilt", "before1980"])
y = df["before1980"]
# check for missing value and fill with column mean if needed
print("Missing values per column in X: ")
print(x.isna().sum())

# If there are missing values, impute with column mean 

x= x.fillna(x.mean())

```

```{python}
# Train-test split
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.20, random_state=42)

print("Train shape:", x_train.shape, "Test shape:", x_test.shape)
```

```{python}
# Train Random Forest classifier
model = RandomForestClassifier(n_estimators=300, random_state=42)
model.fit(x_train, y_train)

```

```{python}
# predictions & probabilities
y_pred = model.predict(x_test)
# predicted probability for positive class (before_1980 = 1)
y_proba = model.predict_proba(x_test)[:, 1]

```

```{python}
# evaluation metrics
acc = accuracy_score(y_test, y_pred)
prec = precision_score(y_test, y_pred, zero_division=0)
rec = recall_score(y_test, y_pred, zero_division=0)
f1 = f1_score(y_test, y_pred, zero_division=0)
roc = roc_auc_score(y_test, y_proba)
cm = confusion_matrix(y_test, y_pred)

print(f"Accuracy: {acc:.4f}")
print(f"Precision: {prec:.4f}")
print(f"Recall: {rec:.4f}")
print(f"F1 score: {f1:.4f}")
print(f"ROC AUC: {roc:.4f}")

print("\nClassification report (detailed):")
print(classification_report(y_test, y_pred, zero_division=0))

print("Confusion matrix (rows = true, cols = predicted):")
print(cm)
```
