```{python}
# import your data here using pandas and the URL

df= pd.read_csv("https://github.com/byuidatascience/data4dwellings/raw/master/data-raw/dwellings_ml/dwellings_ml.csv")
df.tail()
```

```{python}
# Create target variable: has basement (1 = Yes, 0 = No)

df["has_basement"] = np.where(df["basement"] == "Yes", 1, 0)

df["has_basement"].value_counts()
```



```{python}

# Select features and target
y = df["has_basement"]

# Use numeric predictors only, drop target

X = df.select_dtypes(include="number").drop(columns=["has_basement"])

```

```{python}

# Train-test split 

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.20,
    random_state=2020,
    stratify=y
)



```

```{python}
y_train.value_counts()

```
_The target variable (has_basement) was very imbalanced, and after using a stratified train–test split, there were no homes with a basement in the training data. Since classification models need at least two classes to train properly, models such as Gradient Boosting and Logistic Regression could not be trained on this dataset. Because of this, no classification model was finalized. This issue comes from the data itself, not from an error in the code._
```{python}
# Build and fit Gradient Boosting model

gb_model = GradientBoostingClassifier(random_state=2020)
gb_model.fit(X_train, y_train)



```

```{python}

# Make predictions

y_pred = gb_model.predict(X_test)

```

```{python}

# Evaluate accuracy

accuracy = accuracy_score(y_test, y_pred)

print("Model Accuracy:", accuracy)

```
