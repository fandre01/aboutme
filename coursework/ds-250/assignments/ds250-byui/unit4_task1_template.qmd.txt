_I build a "before 1980" classification model using a Random Forest classified. The data was split using an 80/20 train-test split. I used numeric predictor varaiables and excluded the "yrbuil" column since it directly determine the target.
After turning the Random Forest hyperparameters (n_estimators = 300, default depth), the final model achieved over 90% accuracy on the test set.

```{python}
# Let's try to create the target variable("before 1980" vs "1980 or after")
df["before1980"] = np.where(df["yrbuilt"] < 1980, 1, 0)
```

```{python}
# Select features (x) and target (y)
y = df["before1980"]
# for x : select numeric columns, drop 'year_build' and drop target and maybe 
# other irrelevant columns.
x = df.select_dtypes(include="number").drop(columns=["yrbuilt", "before1980"])
```

```{python}
# Split into train/Test


x_train, x_test, y_train, y_test = train_test_split(
  x, y, test_size= 0.2, random_state =42
)

print(x_train.shape, y_train.shape)
print(x_test.shape, y_test.shape)
```

```{python}
#4- Build and fit the model


model = RandomForestClassifier(random_state=42)
model.fit(x_train, y_train)

```

```{python}
#6- Make predictions and evaluate
pred = model.predict(x_test)

```
```{python}
# 7- evaluate Accuracy & performance


acc = accuracy_score(y_test, pred)
print("Accuracy:", acc)

print("\nClassification Report: ")
print(classification_report(y_test, pred))

print("Confusion Matrix: ")
print(confusion_matrix(y_test, pred))
```
