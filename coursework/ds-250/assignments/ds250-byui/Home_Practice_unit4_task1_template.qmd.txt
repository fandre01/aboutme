## QUESTION

__Build a classification model labeling houses as being built “before 1980” or “during or after 1980”.__ Your goal is to reach or exceed 90% accuracy. Report your final model choice and any other model parameters you may have tweaked (train-test split ratio, tuning parameters, etc).  

_type your write-up and analysis here_

```{python}
# Include and execute your code here
# Create the Feature and the target (X, Y)
df["before1980"] = np.where(df["yrbuilt"]< 1980, 1, 0)

```

```{python}
# Select the feature and the target
y = df["before1980"]

x= df.select_dtypes(include= "number").drop(columns=["before1980", "yrbuilt"])
```


```{python}
# split the model
x_train, x_test, y_train, y_test = train_test_split(
  x, y, train_size= 0.2, random_state=42
)
```

```{python}
#build the model and fit the model

model = RandomForestClassifier(random_state=42)
model.fit(x_train, y_train)
```

```{python}
# make prediction
pred = model.predict(x_test)
```

```{python}
# check for acurrancy and other perfomance
acc = accuracy_score(y_test, pred)
print("Accurancy:", acc)


print("\nConfusion_matrics")
print(confusion_matrix(y_test, pred))

print("\nClassification_Report")
print(classification_report(y_test, pred))
```
